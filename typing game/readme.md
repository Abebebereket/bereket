Typing Skill Test Web Application

This is a simple web application I built to practice my programming skills while creating something useful and relevant to my work. As a data entry professional, typing speed and accuracy are essential, so I decided to create a Typing Skill Test app that measures how fast and accurately users can type a given text.

Features
 • Randomly generated sentences or quotes to type
 • Real-time typing feedback (speed and errors)
 • Words Per Minute (WPM) and accuracy calculation
 • Simple and clean user interface
 • Responsive design for both desktop and mobile

Technologies Used
 • HTML
 • CSS
 • JavaScript

Why I Built This

I’m currently learning web development, and I believe the best way to improve is by building real projects. This project helped me understand how to work with user input, timers, DOM manipulation, and basic logic—all essential programming concepts. It also connects well with my job as a data entry professional, making the project both fun and practical.
